- DTO 转换规范：在 REST 层使用 `BeanUtil.cp` 将 Request/Entity 转换为 DTO 或 Response 对象，保持层级间数据隔离。
- 会话上下文注入：在 Service 或 REST 层通过 `IdentityContext.getUserCode()` 自动获取当前登录用户标识，而非从前端参数直接透传。
- 路由常量管理：所有 API 路径统一定义在 `Route` 接口的静态常量中，并使用 `@ApiDesc` 注解进行接口文档描述。
- 分页查询模式：Service 层统一使用 `PageQuery.page(dto, mapper::method)` 包装 MyBatis 查询结果，返回标准化的 `PageData` 对象。
