- REST 控制器统一继承自框架规范，使用 `@Tag` 和 `@Operation` 注解维护 Swagger 文档，并通过 `Route` 接口集中管理 API 路径常量。
- 服务层继承泛型 `BaseService<Entity, Mapper>`，复用基础 CRUD 能力，并在 `create/update` 方法中嵌入业务特有的重复性检查与元数据校验。
- 请求与响应对象严格隔离，分别定义在 `bean.req` 和 `bean.resp` 包下，通过 `BeanUtil.cp` 在 Controller 与 Service 之间进行 DTO/Entity 转换。
- MyBatis XML 映射文件统一存放于 `resources/mapper` 目录，命名与 Java Mapper 接口保持一致，复杂查询逻辑通过 XML 中的动态 SQL 实现。
