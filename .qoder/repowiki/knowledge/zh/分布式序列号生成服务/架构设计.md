- **自动配置入口**：通过 `SeqAutoConfig` 结合 Spring Boot 的 `AutoConfiguration.imports` 实现模块的自动装配与组件扫描。
- **分层架构**：遵循标准的 Controller-Service-Mapper 模式。`SequenceRest` 暴露 HTTP 管理接口；`MdmSequenceService` 封装核心业务逻辑，包括序列号的原子性生成（采用 SERIALIZABLE 隔离级别与 synchronized 锁）；`SeqApi` 作为内部 API 供其他模块调用生成逻辑。
- **数据访问**：基于 MyBatis，通过 `MdmSequenceMapper` 及其 XML 映射文件操作 `mdm_sequence` 表，实现序列状态的持久化与并发控制。
