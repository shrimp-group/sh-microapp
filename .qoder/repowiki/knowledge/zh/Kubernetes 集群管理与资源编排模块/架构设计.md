- **分层架构**：遵循 REST (`rest`) -> Service (`service`) -> Custom API (`custom`) -> Helper/Mapper (`helper`/`mapper`) 的调用链路。
- **核心抽象**：定义 `K8sApi` 接口统一资源操作（list/yaml/create/update/delete），通过 `K8sHelper` 根据 Kind 动态路由至 `custom.impl` 下的数十种具体实现类（如 `K8sDeploymentImpl`）。
- **连接管理**：`KubeConfigHelper` 负责从数据库加载集群凭证，处理复杂的 SSL/TLS 握手与证书解析，并维护 `ApiClient` 的内存缓存（10分钟 TTL）。
- **数据持久化**：利用 MyBatis 管理 `k8s_config` 表，存储集群连接信息；通过 Spring Boot AutoConfiguration (`K8sAutoConfig`) 完成组件扫描与 Mapper 注册。
