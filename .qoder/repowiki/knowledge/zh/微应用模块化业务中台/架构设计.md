- **Starter 驱动集成**：所有子模块均遵循 Spring Boot AutoConfiguration 规范（`*AutoConfig.java` + `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`），作为独立 Starter 被主应用按需依赖注入，实现零配置启动。
- **统一分层契约**：严格遵循 `rest` (控制层) -> `service` (业务层) -> `mapper` (数据层) 的分层架构，并统一使用 `sh-web` 提供的 `IdReq`、`PageReq`、`EntityResp` 等基础 Bean 类，确保跨模块接口风格一致。
- **标准化 API 路由**：采用 `/module/resource/operation` 的统一 URI 结构（如 `/dict/type/page`），并通过 `Route` 常量类集中管理路径，配合全局响应拦截器（如 `micro-mask`）实现跨切面功能。
- **AI 辅助治理体系**：根目录维护 `.agents/skills` 与 `.trae/specs`，为每个子模块定义了标准化的开发技能（SKILL.md）与需求规格（spec.md），实现了从需求到代码生成的自动化闭环。
