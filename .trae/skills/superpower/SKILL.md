# Superpower Skill

This skill provides enhanced coding capabilities for complex development tasks.

## When to Invoke

- User needs advanced code generation or scaffolding
- User requests code refactoring or optimization
- User faces complex debugging challenges
- User wants to improve code quality, performance, or architecture
- User needs help with design patterns or best practices

## Capabilities

1. **Code Generation**: Generate boilerplate, scaffolding, and implementation code
2. **Refactoring**: Restructure code for better readability, maintainability, and performance
3. **Optimization**: Identify and resolve performance bottlenecks
4. **Debugging**: Analyze and fix complex bugs and issues
5. **Architecture**: Provide design pattern recommendations and architectural guidance
6. **Best Practices**: Enforce coding standards and best practices

## Usage Guidelines

- Always analyze existing code patterns before generating new code
- Follow project conventions and coding style
- Consider performance implications of generated code
- Provide clear explanations for refactoring and optimization decisions
- Ensure backward compatibility when making changes
