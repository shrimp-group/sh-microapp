- 采用 Spring Boot 自动配置机制，通过 `RmcheckAutoConfig` 扫描组件并注册 MyBatis Mapper。
- 遵循经典分层架构：`rest` 层处理 HTTP 请求，`service` 层实现业务逻辑（如规则 CRUD、表/字段存在性校验），`mapper` 层负责数据持久化。
- 核心校验逻辑封装在 `RmCheckApi` 中，利用 Java 反射动态获取实体字段值，并结合 `CheckMapper` 执行动态 SQL 跨表查询依赖。
- 数据模型分为规则主表 (`RmCheckRule`) 和规则项子表 (`RmCheckRuleItem`)，支持针对特定表字段的精细化校验配置。
