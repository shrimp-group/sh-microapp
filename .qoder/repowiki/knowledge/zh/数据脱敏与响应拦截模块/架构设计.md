- **自动配置入口**：`MaskAutoConfig` 作为 Spring Boot 自动配置类，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册，启用组件扫描与 Mapper 扫描。
- **核心拦截层**：`MaskResponseAdvice` 实现 `ResponseBodyAdvice`，在响应序列化前根据请求路径匹配脱敏规则，利用 Guava Cache 缓存路由映射，并通过 JSONPath 动态修改响应体。
- **规则管理层**：`MdmMaskRuleService` 继承 `BaseService` 提供规则的 CRUD 及唯一性校验；`MaskCache` 负责从数据库加载规则至本地内存，并通过 Redis 实现多实例间的缓存失效同步（分布式缓存一致性）。
- **数据持久层**：`MdmMaskRuleMapper` 配合 XML 定义 SQL，支撑规则的存储与查询。
