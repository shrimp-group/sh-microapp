- **分层架构**：遵循 REST (`rest`) -> Service (`service`) -> Mapper (`mapper`) 的经典三层结构，通过 `ReportAutoConfig` 实现 Spring Boot 自动装配。
- **核心引擎**：`ReportSqlHelper` 负责动态 SQL 的安全解析（Druid/JSqlParser）、MyBatis `MappedStatement` 运行时注册及结果集驼峰转换。
- **缓存机制**：`ReportCache` 利用 Redis Pub/Sub 实现分布式环境下的报表定义内存缓存同步，提升高频查询性能。
- **数据模型**：区分元数据实体（`entity`）、接口传输对象（`dto`/`req`/`resp`）及历史版本记录（`ReportDefinitionHis`）。
- **依赖方向**：内部依赖 `sh-mybatis`、`sh-redis` 等基础框架组件，外部通过 `easyexcel` 支持导出功能。
