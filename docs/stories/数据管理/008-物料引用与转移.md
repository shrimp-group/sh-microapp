# Story: 物料引用与转移

## 描述
作为业务系统，管理素材与业务对象的引用关系并支持所有权转移，追踪素材使用情况和变更归属。

## 参与者
| 角色 | 说明 |
|------|------|
| 业务系统 | 调用引用绑定/解绑/转移API |
| 系统 | 后端服务，管理引用关系和转移日志 |

## 流程图
```mermaid
sequenceDiagram
    participant 业务系统
    participant 素材服务

    业务系统->>素材服务: 引用绑定(materialCode+bizType+bizCode)
    素材服务->>素材服务: 校验素材未被引用或允许重复引用
    素材服务-->>业务系统: 绑定成功

    业务系统->>素材服务: 引用解绑
    素材服务->>素材服务: 删除引用记录
    素材服务-->>业务系统: 解绑成功

    业务系统->>素材服务: 所有权转移
    素材服务->>素材服务: 记录转移日志并更新归属
    素材服务-->>业务系统: 转移成功

    业务系统->>素材服务: 删除前引用检测
    素材服务-->>业务系统: 返回所有引用该素材的业务列表
```

## 验收标准
- [ ] 引用绑定：Given 素材未被引用, When 执行引用绑定(materialCode+bizType+bizCode), Then 成功绑定
- [ ] 引用解绑：Given 素材已被某业务引用, When 执行解绑, Then 删除引用记录
- [ ] 所有权转移：Given 需要转移素材所有权, When 执行转移操作, Then 记录转移日志并更新归属
- [ ] 引用检测：Given 删除素材前, When 执行引用检测, Then 返回所有引用该素材的业务列表
