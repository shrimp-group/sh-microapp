- **分层架构**：采用 REST (`rest`) -> API Facade (`api`) -> Service Strategy (`service`) -> Storage Provider (`service/impl`) 的分层设计。
- **策略模式**：`FileosService` 接口定义了存储操作规范，通过 `AliOssServiceImpl` 和 `S3ServiceImpl` 实现多云适配，由 `AbstractFileosApi` 根据 Bucket 配置动态路由。
- **数据持久化**：使用 MyBatis 映射 `mdm_fileos_*` 系列表管理文件元数据、Bucket 配置、目录结构及分片上传状态。
- **自动化装配**：通过 `FileosAutoConfig` 配合 Spring Boot AutoConfiguration 机制实现组件扫描与 Mapper 注册。
- **辅助组件**：集成 `BucketCache` 缓存配置信息，`DirectoryHelper` 异步维护虚拟目录树，`MultipartCleanupJob` 定期清理过期分片。
