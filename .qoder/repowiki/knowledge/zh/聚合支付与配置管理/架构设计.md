- 采用 Spring Boot Starter 自动装配机制（`PayAutoConfig`），通过 `@MapperScan` 和 `@ComponentScan` 初始化模块上下文。
- 遵循分层架构：`rest` 层定义路由契约（`Route`）并处理 HTTP 请求，`service` 层编排业务逻辑，`helper` 层封装第三方支付 SDK（Alipay/Wechat）交互，`mapper` 层负责数据持久化。
- 引入 SPI 扩展点（`PayNoticeSpi`）实现支付成功后的业务解耦，允许外部系统订阅支付结果。
- 使用本地缓存结合 Redis 分布式锁/标记（`AlipayClientCache`）管理多租户支付客户端实例，平衡性能与配置实时性。
