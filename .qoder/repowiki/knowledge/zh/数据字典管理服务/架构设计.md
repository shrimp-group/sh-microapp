- **自动配置入口**：`DictAutoConfig` 通过 `@MapperScan` 和 `@ComponentScan` 初始化组件，并由 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册为 Spring Boot 自动配置类。
- **分层架构**：遵循标准的 Controller-Service-Mapper 模式。`rest` 包定义 RESTful 接口（如 `DictRest`），`service` 包处理业务逻辑（如 `MdmDictService`），`mapper` 包配合 XML 文件完成持久化操作。
- **缓存机制**：`DictCache` 组件利用 Redis Pub/Sub 实现分布式缓存同步。采用内存静态变量存储字典映射，并通过 3 秒防抖策略优化高频刷新场景下的数据库查询压力。
- **依赖方向**：模块内部依赖 `sh-mybatis` 进行数据访问，依赖 `sh-redis` 实现缓存，依赖 `iam-sdk` 获取会话用户信息。
