- **自动配置入口**：通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册 `PdfAutoConfig`，实现模块的即插即用。
- **分层架构**：遵循标准的 Spring Boot 分层设计。`rest/PdfTemplateRest` 处理 HTTP 请求；`service/MdmPdfTemplateService` 封装业务逻辑（含唯一性校验）；`mapper` 层配合 MyBatis XML 进行数据持久化。
- **核心渲染引擎**：`helper/PdfHelper` 整合 Thymeleaf 进行模板变量替换，并利用 Flying Saucer (iText5) 将 HTML 转换为 PDF，支持中文字体（宋体）嵌入。
- **多级缓存策略**：`cache/PdfTemplateCache` 实现了基于 Redis 信号量的本地内存缓存。通过定时任务轮询 Redis 中的更新时间戳，实现多实例环境下的缓存自动失效与同步。
- **对外 API**：`api/PdfApi` 提供非 REST 的服务间调用接口，直接根据模板编码生成 PDF 文件或流。
