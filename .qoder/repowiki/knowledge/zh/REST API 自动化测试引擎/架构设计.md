- **自动装配入口**：`AutoTestAutoConfig` 配合 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 实现 Spring Boot Starter 式的自动加载。
- **核心执行流**：`ApiScanner` 负责反射扫描 `@RestController` 及自定义 `@Router` 注解提取接口元数据；`TestExecutor` 利用 `MockMvc` 发起请求，并通过 `MockHelper` 动态替换 Controller 依赖为 Mockito 实例以隔离外部系统。
- **数据与报告**：`TestDataGenerator` 根据参数类型递归生成默认测试值；`ReportGenerator` 将执行结果序列化为 Markdown 和 HTML 格式的报告文件。
- **交互层**：`AutoTestRest` 暴露 `/micro-autotest/api/list`、`/run` 及 `/report` 等端点，提供可视化的测试触发与结果查询能力。
