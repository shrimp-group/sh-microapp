- **分层架构**：遵循 Controller (`rest`) -> Service (`service`) -> Mapper (`mapper`) 的经典三层结构，通过 `DbviewAutoConfig` 进行组件扫描与 MyBatis 映射配置。
- **动态数据源核心**：利用 `sh-dynamicdb` 框架，通过 `DynamicDataSourceHolder` 在线程上下文中切换数据源 ID，`DbviewDataSourceFactory` 负责根据 ID 从数据库加载配置并构建 `DataSourceInfo`。
- **缓存策略**：使用 Redis (`RedisHelper`) 缓存元数据（表结构、索引等）和数据源配置，Key 格式规范为 `dbview:metadata:{id}:...` 和 `dbview:datasource:{id}`，并在 DDL 执行后自动失效相关缓存。
- **安全与审计**：`DbviewDatasourcePermissionService` 实现基于用户和 SQL 类型（READ/WRITE/DDL）的细粒度权限校验及危险操作（如无 WHERE 更新）拦截；所有 SQL/DDL 执行均通过 `DbviewSqlHistoryService` 记录审计日志。
- **入口配置**：通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册 `DbviewAutoConfig`，实现 Spring Boot 自动装配。
