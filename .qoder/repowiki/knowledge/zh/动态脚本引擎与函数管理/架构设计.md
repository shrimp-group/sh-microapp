- **分层架构**：遵循标准的 Controller-Service-Mapper 模式。`rest` 层处理 HTTP 请求，`service` 层封装业务逻辑（如 `FunFunctionService`），`mapper` 层通过 MyBatis 进行数据持久化。
- **策略模式引擎**：`engine` 包定义了抽象基类 `ScriptEngine`，并通过 `ScriptService` 根据语言类型（JavaScript, Python, Groovy, QLExpress, Ruby）动态实例化具体的实现类（如 `JavaScriptEngineImpl`）。
- **自动配置**：通过 `FunAutoConfig` 和 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 实现 Spring Boot Starter 式的自动装配，扫描 Mapper 和组件。
- **数据模型**：`bean` 包严格区分了持久化实体（`entity`）、数据传输对象（`dto`）、请求参数（`req`）和响应结果（`resp`）。
