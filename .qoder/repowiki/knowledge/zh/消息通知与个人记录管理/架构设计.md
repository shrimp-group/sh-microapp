- **模块形态**：基于 Spring Boot AutoConfiguration (`MsgAutoConfig`) 的独立业务 Starter，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 实现自动装配。
- **分层架构**：遵循标准的 Controller-Service-Mapper 结构。`rest` 层处理 HTTP 请求并定义路由常量 (`Route`)；`service` 层继承 `BaseService` 处理核心业务逻辑（如消息分发、已读状态更新）；`mapper` 层配合 XML 完成数据持久化。
- **对外接口**：提供 `MsgApi` 作为编程式 API，供其他微服务直接调用以发送系统通知；同时暴露 RESTful 接口分为管理员端（模板与全局通知管理）和个人端（消息列表、详情、已读操作）。
- **依赖方向**：依赖内部框架组件 `sh-mybatis`、`sh-redis` 以及身份认证 SDK `iam-sdk` 获取当前会话用户信息。
