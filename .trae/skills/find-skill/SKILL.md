# Find Skill

This skill provides advanced code search and navigation capabilities across the entire codebase.

## When to Invoke

- User asks to find specific code, functions, classes, or variables
- User needs to trace references or usages of a symbol
- User wants to explore project structure or locate implementations
- User needs to search for patterns, configurations, or specific text across files

## Capabilities

1. **Symbol Search**: Locate function, class, variable, and type definitions
2. **Reference Tracing**: Find all usages and references of a symbol
3. **Pattern Search**: Search for code patterns using regex or text matching
4. **File Discovery**: Locate files by name, path, or glob pattern
5. **Structure Exploration**: Navigate project directories and understand code organization

## Usage Guidelines

- Combine multiple search strategies for comprehensive results
- Use glob patterns for file name searches
- Use regex patterns for content searches
- Provide context around search results for better understanding
- Cross-reference findings to build a complete picture of code relationships
